# CMIP6 multimodel streamflow for the Delaware River Basin

This repository processes CMIP6-driven streamflow projections for the Delaware River Basin (DRB), runs them through [Pywr-DRB](https://github.com/Pywr-DRB/Pywr-DRB), and derives monthly percent-change profiles of New York City (NYC) reservoir inflow under future climate. Two of those profiles are the climate-adjusted scenarios used in the companion study repository `StochasticExploratoryExperiment`.

## Data source

Streamflow comes from the ORNL 9505 V3 Flow dataset: daily RAPID-routed flows from the PRMS and VIC5 hydrologic models forced with DBCCA-downscaled CMIP6 projections (seven GCMs; SSP1-2.6 for 1980-2019, SSP2-4.5 and SSP3-7.0 for 2020-2059 and 2060-2099) and with Daymet and Livneh historic forcing.

- Naming convention and file contents: [dataset README](https://hydrosource2.ornl.gov/files/SWA9505V3Flow/README_9505V3Flow.txt)
- Download: [HydroSource](https://hydrosource2.ornl.gov/files/SWA9505V3Flow/) or [Globus](https://doi.org/10.13139/OLCF/2318650) (recommended)

Dataset names follow `<model>_RAPID_<GCM>_<ssp>_<run>_DBCCA_Daymet_<start>_<end>` for projections and `<model>_RAPID_<forcing>_<start>_<end>` for historic runs, for example `PRMS_RAPID_ACCESS-CM2_ssp245_r1i1p1f1_DBCCA_Daymet_2020_2059` and `PRMS_RAPID_Daymet2019_1980_2019`.

## Layout

| Path | Contents |
|---|---|
| `P1_` to `P4_*.py` | Pywr-DRB workflow: extract node flows from netCDF, build model inputs, run simulations, plot storages |
| `S1_` to `S5_*.py` | Scenario-selection workflow: compare hydrologic models, compute flow statistics, select and plot scenarios |
| `config.py` | Paths, dataset list, and scenario-selection settings shared by all scripts |
| `utils.py`, `scenario_utils.py` | Dataset-name parsing and baseline lookup; filtering and ranking helpers |
| `data/drb_pywrdrb_node_metadata.csv` | Pywr-DRB node to NHDPlus COMID mapping used by P1 |
| `pywrdrb/inputs/<dataset>/` | `gage_flow_mgd.csv` and `catchment_inflow_mgd.csv` per dataset (tracked); other inputs regenerated by P2 |
| `pywrdrb/outputs/`, `pywrdrb/json/` | Pywr-DRB results and model definitions from P3 (not tracked) |
| `stats/` | CSV outputs of S2 and S3 |
| `figures/` | Figures from S1, S3, S4, S5 and P4 |
| `run_workflow.sh` | SLURM batch script running the workflow |

## Environment

```
module load python/3.11.5        # or any Python 3.11
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Requires `pywrdrb>=2.1.0`. The results in this repository were generated with pywrdrb installed from commit `949501f` of the Pywr-DRB repository, and the package versions in `requirements.txt`.

Run scripts from the repository root. Every script imports `config.py`, which requires `pywrdrb/inputs/` to exist. On a cluster, `mkdir logs` then `sbatch run_workflow.sh`.

## Pywr-DRB workflow (P1 to P4)

These steps are only needed when new datasets are added. The processed `gage_flow_mgd.csv` and `catchment_inflow_mgd.csv` files are tracked in the repository, and the scenario-selection scripts do not use the Pywr-DRB simulation results.

| Script | Purpose |
|---|---|
| `P1_extract_netcdf_flows.py` | Extracts daily flow at the Pywr-DRB nodes from the netCDF files in `netcdf/<dataset>/` and writes `pywrdrb/inputs/<dataset>/gage_flow_mgd.csv` |
| `P2_prep_pywrdrb_inputs.py` | Builds catchment inflows, predicted inflows, and extrapolated and predicted diversions for each dataset (MPI) |
| `P3_run_pywrdrb_simulations.py` | Runs a Pywr-DRB simulation per dataset (MPI) |
| `P4_plot_nyc_storages.py` | Plots aggregate NYC reservoir storage across a set of simulations |

## Scenario-selection workflow (S1 to S5)

Run in order. S2 must precede S3, and S3 must precede S4 and S5. S1 is independent.

| Script | Purpose |
|---|---|
| `S1_compare_historic_data.py` | Compares the PRMS and VIC5 Daymet historic runs with the `pub_nhmv10_BC_withObsScaled` reconstruction for NYC aggregate inflow (climatology, variability, NSE, bias, correlation, RMSE, peak timing, seasonal distribution). PRMS wins 6 of 7 summary metrics and is used from here on |
| `S2_calculate_annual_monthly_stats.py` | Annual and monthly mean and standard deviation of NYC inflow for every dataset, and monthly percent changes relative to a baseline |
| `S3_find_scenarios.py` | Filters and ranks the projection ensemble and selects the `low` and `high` scenarios |
| `S4_plot_scenarios.py` | Figure of the selected scenarios against the ensemble |
| `S5_plot_annual_flows.py` | Figure of annual flow changes across the ensemble with the selected scenarios marked |

### Selection method

Settings are in `config.py`.

1. Ensemble: PRMS projections under SSP2-4.5 and SSP3-7.0 for 2020-2059 (13 GCM runs).
2. Quantity: percent change in mean monthly NYC inflow relative to the PRMS Daymet historic run (1980-2019), from S2.
3. Drop any GCM run with an IQR outlier (1.5 IQR) in any month, and any run with a negative change in annual flow.
4. Rank the remaining runs by the mean of their 12 monthly percent changes.
5. `low` is the lowest-ranked run and `high` the highest.

Current result: `low` is MPI-ESM1-2-HR SSP2-4.5 (mean change +2.8%; wetter winter, drier summer) and `high` is CNRM-ESM2-1 SSP2-4.5 (mean change +15.3%; wetter winter).

## Outputs

| File | Contents |
|---|---|
| `stats/datasets_nyc_inflow_{annual_means,annual_median,annual_stds,monthly_means,monthly_stds}.csv` | Flow statistics per dataset |
| `stats/diff_relative_to_dataset_baseline/nyc_inflow_monthly_mean_{diff,frac,prc_change}_by_dataset_ssp_and_period.csv` | Monthly mean change relative to each dataset's own historic run |
| `stats/diff_relative_to_reconstruction/...` | Same, relative to `pub_nhmv10_BC_withObsScaled` |
| `stats/diff_relative_to_dataset_baseline/selected_scenarios/nyc_inflow_selected_scenarios_PRMS_2020_2059.csv` | Monthly percent-change profiles of the `low` and `high` scenarios |
| `.../selected_scenarios/nyc_inflow_selection_summary_PRMS_2020_2059.csv` | GCM name, mean change and rank of each selected scenario |
| `.../selected_scenarios/nyc_inflow_all_weighted_averages_PRMS_2020_2059.csv` | Mean monthly change of every run that passed the filters |
| `figures/S1_model_comparison_summary.png` | S1 summary figure |
| `figures/diff_relative_to_dataset_baseline/selected_scenarios/*.png` | S3, S4 and S5 figures |

## Use in the companion study

`stats/diff_relative_to_dataset_baseline/nyc_inflow_monthly_mean_prc_change_by_dataset_ssp_and_period.csv` and `stats/diff_relative_to_dataset_baseline/selected_scenarios/nyc_inflow_selected_scenarios_PRMS_2020_2059.csv` are copied into the `data/` folder of `StochasticExploratoryExperiment`, where the `low` and `high` columns define the `climate_adjusted_low` (AKA WWDS) and `climate_adjusted_high` (AKA WWSS) ensembles.
